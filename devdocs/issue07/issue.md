# 「家計の見直し」をあとからフローに差し込みたい

住宅ローンを組むタイミングで家計の見直しをして、生命保険や今後のライフイベントで発生する出費に応じた計画を組んでおくことは顧客にとって有益なので、銀行側としてはぜひおすすめしたい。

だが、住宅ローンの申し込み～審査、実行のフロー上で家計の見直しは必須ではないし、顧客は「今は住宅ローンを早く契約したい」と思っているので、余計な手順が勝手に挟まれるのは悪印象だ。

住宅ローンナビに以下のようなUIを追加したい。

1. 「家計の見直し」というボタンを「必須でない感じ」を出しつつ画面上に表示しておく
2. ボタンをクリックしたら、この住宅ローン申込みのタイミングで家計を見直すメリットを説明する画面を表示する。これも押し付けがましくないデザインで表示する。
3. 説明画面の下部に「ライフプランアドバイザーに面談予約する」というボタンを表示する
4. ボタンをクリックしたら、来店予約画面に遷移する
